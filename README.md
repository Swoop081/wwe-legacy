# WWE Legacy v0.14.05 — Consolidated Tabled UX + Booster Collation

This is a no-assets overlay build for the current WWE Legacy flat-asset installation. Copy these files over the existing v0.14.04/current game folder and keep your existing `assets/` directory in place.

Included in v0.14.05:
- exactly 3 rotating Live Events, with Money in the Bank always below them;
- Birthday Bash / RAW LIVE specials replace a generic rotating slot rather than increasing the count;
- Auto Counter card selection preserves horizontal hand scroll position;
- John Cena’s authored Season 1 physical card is explicitly centered in its promo bay;
- defeated Live Event opponents get a large check overlay on their Superstar card;
- boosters allow at most 2 non-Normal printings and at most 1 Sapphire/Ruby per five-card pack;
- Superstar pity remains 100 packs and the natural Superstar chase remains 2%.

The `assets/` folder is intentionally not included.
