# WWE Legacy v1.1.84 — Remaining Released Set Move Identity Audit

Scope: all **56 Superstars** across the seven released sets not covered by the prior NXT/Ruthless Aggression audit.

Audited fields for every Superstar-specific move: Finisher/Trademark role, physical move type, Method, submission flag, grounded/standing state, search targets, foreign Superstar wording, and recommended-deck reachability.

## Audit outcome

- All 56 Superstars were inspected.
- All Finishers in this scope now obey the no-Method rule.
- Shared `Spear` also had a stale Strength Method removed; its current users are banked future decks, not the active-81 field.
- No real broken search target remains in the seven-set scope.
- No true cross-Superstar cloned wording remains; the only heuristic false positive is the word `Edge` inside **The Razor’s Edge**.
- Move type and gameplay Method are intentionally treated as separate concepts. A card may be physically a Grapple while using Strike/Agility/Technical as its WWE Legacy Method lane.
