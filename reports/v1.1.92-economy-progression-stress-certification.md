# v1.1.92 — Economy + Progression Stress Certification

## Scope
Stress-test the current WWE Legacy economy without changing rewards merely to make graphs look smoother.

Audited:
- Booster collation and Superstar pity
- Merch frequency
- Season 1 XP pace and reward road
- Daily Spin expected value
- Live Event reward flow
- Store pricing
- Championship Road booster cadence

## Locked economy constants
- Booster: 4 collectible slots + exactly 1 Merch
- Superstar chase: 2% per eligible pack
- Global hard pity: 100 consecutive misses
- Store booster: 300 UP
- Store Superstar: 2,500 UP
- Season: 50 tiers × 100 XP = 5,000 XP
- Match XP: 5 per win / 0 per loss
- Daily challenge: 10 XP
- Weekly challenge: 25 XP
- Daily Spin cooldown: 24 hours

## Daily Spin EV
Current wheel has six equally likely wedges:
- 50 UP
- 15 Season XP
- 1 booster
- 150 UP
- 1 Premium Merch
- 30 Season XP

Expected value per daily spin:
- 33.33 UP
- 7.5 Season XP
- 0.167 booster
- 0.167 standalone Merch

This is modest enough that Daily Spin supplements play rather than replacing it.

## Season 1 reward road
The 50 tiers contain:
- 23 Trish chase/reward tiers
- 16 booster tiers
- 11 UP tiers
- 1,350 total UP from the tier road

Season completion requires 5,000 XP over 30 days = **166.7 XP/day** on average.

A highly engaged day can currently generate about:
- 75 XP from 15 Daily Live Event wins
- 70 XP from all seven daily challenges
- 25 XP Daily Live Event set-completion bonus
- 7.5 XP expected Daily Spin
= **177.5 XP/day before weekly challenges**.

Weekly challenges add up to 175 XP/week if all seven are completed. This means the full 50-tier chase is demanding but mathematically achievable for an engaged player. It is not dependent on buying progression.

## 1,000-account / 30-day stress scenario
Scenario deliberately models a highly engaged player:
- Daily Spin every day
- all 15 Daily Live Event wins every day
- all seven daily challenges every day
- three Live Event clear boosters every day
- all seven weekly challenges for four weeks

Results:
- all profiles reach Tier 50
- 90 guaranteed Live Event boosters opened
- average unlocked Superstar count: **2.81** including the starter
- median unlocked Superstars: **3**
- 10th–90th percentile: **1–5**
- average natural Superstar hits: **1.81**
- average ending UP from modeled non-tier sources: **989.5**
- median: **1,000 UP**
- 10th–90th percentile: **600–1,400 UP**
- average global pity position after 90 packs: **40.45**

The Superstar chase remains meaningfully rare. Ninety free-event boosters across an entire month do not flood the roster.

## Merch
Every booster guarantees one Merch card. A player opening 90 Live Event boosters therefore receives 90 Merch cards before Daily Spin Merch.

This sounds high as a raw item count, but Merch is consumable, non-stackable and lasts only 1/3/5 eligible matches. The guaranteed slot therefore behaves as a replenishment economy rather than a permanent-power collection slot.

No reduction is recommended at this stage.

## Championship Road
Each 40-match Road grants a set-specific booster every four victories: **10 boosters per full clear**.

That is a meaningful reward for a long mode and does not by itself threaten the 2% Superstar chase because the same global pity/chase rules remain in force when those boosters are opened.

## Store
At 300 UP per booster and 2,500 UP per direct Superstar, the store preserves a large distinction between random progression and guaranteed roster acquisition.

The direct Superstar price is intentionally expensive: it acts as a long-term certainty valve rather than the default acquisition route.

## Findings / watch items
1. **No economy-breaking inflation was found.**
2. Season 1 is achievable for highly engaged players, but its 166.7 XP/day requirement is intentionally demanding. Casual completion should not be assumed.
3. Guaranteed Merch volume is high in absolute terms but justified by match-limited consumption; monitor actual player inventory once physical play data exists.
4. The 100-pack pity is still meaningful. A month of very active Live Event play reaches 90 packs, close enough to make pity visible without guaranteeing multiple Superstars.
5. The strongest economy risk is not currency inflation but **reward-density perception**: a very active player can receive 90 Live Event Merch cards plus Daily Spin/Season rewards. This should be evaluated on-device for presentation fatigue, not nerfed numerically before testing.

## Decision
**No gameplay/economy values changed in v1.1.92.**

The current economy is internally coherent enough to retain through physical testing. v1.1.92 adds a repeatable stress harness and records the economy baseline so later changes can be compared against the same assumptions.
