# v1.1.93 — Locked Core Rules Regression Certification

## Purpose
Convert WWE Legacy's accepted core gameplay rules into a compact permanent regression gate so future roster, card, UI and content work cannot silently change match fundamentals.

## New permanent regression coverage
`test/v1193-locked-core-rules-regression.test.js` locks:

1. **Lead Off / opening draw**
   - both players start with exactly 5 pages
   - Turn 1 begins immediately with no automatic draw

2. **Normal Control transfer**
   - passing transfers Control
   - the normal transfer advances the turn and replenishes both players

3. **Retained Control draw**
   - after a successful non-Submission Move, the attacker gets no automatic replacement page
   - the defender draws exactly 1 page

4. **Momentum permanence**
   - one normal Momentum placement per turn
   - committed Method Momentum remains after Control cycles
   - turn counters reset without erasing thresholds

5. **Failed pin**
   - ordinary kickout transfers Control to the defender

6. **Pin probability**
   - 0–4 HP = 75%
   - 5 = 70%
   - 10 = 45%
   - 15 = 20%
   - 16+ = 5%
   - existing Amber/Red health gate remains covered by the earlier pin-health suite

7. **Submission architecture**
   - tap threshold equals current HP
   - body-part damage persists after release
   - defender draws on each pressure/response application

8. **Auto Counter**
   - costs escalate 5 / 6 / 7 / 8...
   - payment must still leave at least 2 pages
   - Finishers cannot be Auto Countered
   - Stun blocks Auto Counter

9. **Stun / Grounded**
   - Stun clears when the controller passes
   - existing Move-commit Stun clearing remains covered in the historical gameplay suite
   - grounded Superstar stands automatically when gaining Control

## Certification result
The new v1.1.93 suite passes **9/9**.

A combined current gameplay regression gate covering the new suite plus Auto Counter, retained-Control draw, persistent submissions, pin-health gating, submission response windows and the v1.0.2 launch gameplay locks passes **30/30**.

A broader 37-test run also executed the historical `v01406-grounded-stun-splash` file. Its gameplay assertions passed, but one old presentation assertion still expects the retired Cena Season splash. That is a stale UI/version assertion and is not a gameplay regression. It remains test-harness cleanup debt.

## Gameplay impact
**No gameplay rules or balance values changed in v1.1.93.**

This release strengthens the safety net around the existing rules rather than altering them.
