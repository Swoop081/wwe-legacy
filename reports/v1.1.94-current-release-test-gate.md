# v1.1.94 — Trustworthy Current Release Test Gate

## Problem
The repository had accumulated hundreds of version-specific tests. Many correctly documented an old release when written, but the default `node --test` command treated every historical snapshot as though it were still the current product contract. That produced 169 failures on v1.1.93, overwhelmingly from intentionally superseded content such as Cena Season 1, four-tier printing, old roster counts, retired art paths and earlier balance values.

A test that says “v0.14.20 has X HP” is useful historical evidence; rewriting it to say that v0.14.20 had a later value would make the history false. Deleting it would also lose useful regression archaeology.

## v1.1.94 solution
- Preserve all historical test files unchanged.
- Add `test/current-release-manifest.json` as the explicit current release contract.
- Add `tools/run-current-release-tests.mjs`.
- Change `npm test` and `npm run test:current` to run only the current release manifest.
- Keep `npm run test:historical` as the complete historical scan for archaeology/debt analysis; it is intentionally non-gating until old snapshots are individually reclassified or retired.
