# v1.1.95 — iPhone Infinite Update Reload Hotfix

## Physical iPhone defect
Screen recording showed the Season splash repeatedly disappearing to a near-black frame and repainting, with the UI effectively frozen.

## Root cause
The package/build manifest had advanced to v1.1.94 while `js/config/build.js` still reported `BUILD_VERSION = "1.1.102"` and module cache-busting imports still used `?v=1.1.102`.

The automatic update checker therefore performed this loop:
1. running bundle identifies as 1.1.86;
2. fetched `build.json` reports a newer release;
3. automatic updater navigates to the newer build URL;
4. stale/version-mismatched bundle still identifies as 1.1.86;
5. updater navigates again.

On iPhone this appeared as a rapid black/splash flicker and prevented interaction.

## Fix
- Release/cache identity stamped consistently to **1.1.95**.
- Runtime `BUILD_VERSION` now matches `build.json`.
- Module cache-busting imports are stamped to `?v=1.1.102`.
- `applyAppUpdate()` now refuses a second automatic navigation when the current URL already contains the requested `build` version. A stale bundle can therefore no longer produce an infinite navigation loop.
- Added permanent regression tests for build identity, import stamping and the reload-loop guard.

## Gameplay
No gameplay, roster, card, economy or balance values changed.
