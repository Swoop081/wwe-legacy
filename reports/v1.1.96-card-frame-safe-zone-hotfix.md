# v1.1.96 — iPhone Card Frame Safe-Zone Hotfix

Physical iPhone screenshots identified three related card-frame defects:

- rules backs were sitting underneath the new physical printing frame and could clip left/right content;
- rarity stars and set identity were too close to the physical frame;
- Card Studio was still drawing the retired legacy outer frame before drawing the new physical tier frame, causing the old frame to remain visible at rounded corners.

## Fixes
- Rules-face content now begins inside the physical-frame safe zone and uses slightly tighter typography/spacing to preserve full rules capacity.
- Physical frame safe zone enlarged modestly and corner radius standardized.
- Existing flat/layered fronts receive a tiny centered compatibility inset so baked set identity gains additional edge breathing room while the wider frame consumes the retired perimeter.
- Dynamic rarity stars moved inward.
- Card Studio set logo moved inward/down to the new safe-zone coordinates.
- Card Studio rarity stars moved inward/down to match.
- Shared runtime rarity-star renderer uses identical coordinates.
- Card Studio no longer draws the old legacy frame underneath the physical frame for future exports.

No gameplay, card data, balance or economy changes.
